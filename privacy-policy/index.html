개인정보 처리방침

Chrome 웹 스토어: 설치 페이지
최종 업데이트: 2026년 4월
요약: 이 확장 프로그램은 사용자의 어떠한 개인정보도 수집하거나 외부로 전송하지 않습니다.

1. 수집하는 정보

본 확장 프로그램은 다음의 어떠한 사용자 데이터도 수집하지 않습니다:

  • 개인 식별 정보 (이름, 이메일, 주소 등)
  • 건강 정보
  • 금융 및 결제 정보
  • 인증 정보 (비밀번호, 보안 질문 등)
  • 개인적인 커뮤니케이션 (이메일, 채팅 등)
  • 위치 정보
  • 웹 기록 (방문 페이지 목록 등)
  • 사용자 활동 (클릭, 마우스 위치, 키 입력 등)
  • 웹사이트 콘텐츠 (텍스트, 이미지 등)

2. 로컬 저장소 사용

사용자 편의를 위해 Chrome 확장 프로그램의 chrome.storage.local API를 사용하여 다음 정보를 사용자의 로컬 기기에만 저장합니다:

  • 사용자가 마지막으로 선택한 기업 스타일의 식별자 (예: samsung, kb 등)

이 데이터는 사용자의 기기를 떠나지 않으며, 외부 서버·제3자·개발자에게 전송되거나 공유되지 않습니다. 사용자는 브라우저의 확장 프로그램 관리 화면에서 언제든 해당 데이터를 삭제할 수 있습니다(확장 제거 시 자동 삭제).

3. 제3자 서비스 및 외부 통신

본 확장 프로그램은 외부 서버와 통신하지 않으며, 어떠한 제3자 분석 도구, 광고 네트워크, 추적 서비스도 사용하지 않습니다. 모든 기능은 사용자의 브라우저 내에서만 실행됩니다.

4. 권한 사용 목적

  • activeTab: 사용자가 확장 아이콘을 클릭한 현재 탭(NotebookLM)의 슬라이드 지침 입력 필드에 텍스트를 삽입하기 위해 사용합니다.
  • storage: 위 "2. 로컬 저장소 사용"에 명시된 목적으로만 사용합니다.
  • scripting: NotebookLM 페이지에 스타일 입력 스크립트를 주입하여 기능을 실행하기 위해 사용합니다.
  • host_permissions (https://notebooklm.google.com/*): NotebookLM 페이지의 슬라이드 생성 다이얼로그에만 UI 버튼을 삽입하고 동작하기 위한 최소 권한입니다.

5. 데이터 판매 및 전송 금지

  • 사용자 데이터를 제3자에 판매하거나 전송하지 않습니다.
  • 확장 프로그램의 전용 목적과 관련 없는 용도로 사용자 데이터를 사용하지 않습니다.
  • 신용도 판단 또는 대출 목적으로 사용자 데이터를 사용하지 않습니다.

6. 아동 개인정보 보호

본 확장 프로그램은 만 13세 미만 아동을 특별히 대상으로 하지 않으며, 아동으로부터 어떠한 개인정보도 수집하지 않습니다.

7. 정책 변경

본 처리방침이 변경될 경우 본 페이지의 업데이트 날짜가 갱신되며, 중요한 변경 사항은 Chrome 웹 스토어의 확장 프로그램 페이지를 통해 공지됩니다.

  • 각 기업명은 해당 기업의 슬라이드 스타일을 식별하기 위한 참고적 사용(nominative use)으로만 표기됩니다.
